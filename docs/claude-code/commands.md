## 組み込みスラッシュコマンド

チャット入力欄で `/` に続けてコマンド名を入力します。以下は主に **CLI／デスクトップ**での利用を想定した一覧です。

### プロジェクト初期化・設定

| コマンド | 概要 | 活用場面 |
|---------|------|---------|
| `/init` | `CLAUDE.md` を自動生成してプロジェクトの構成を記録 | 新規リポジトリへの導入時 |
| `/config` | モデル、テーマ、表示などの設定を変更 | 初期セットアップ |
| `/model` | 使用するモデルを切り替え | タスクに応じた使い分け |
| `/settings` | 設定ファイルの内容を確認・編集 | パーミッションやフックの調整 |
| `/permissions` | ツールの許可・拒否設定を管理 | 自動実行を許可するコマンドの制御 |

### レビュー・品質管理

| コマンド | 概要 | 活用場面 |
|---------|------|---------|
| `/review` | プルリクエストをレビュー | コードレビューの効率化 |
| `/pr-comments` | PR に付いたコメントを取得して対応 | レビュー指摘への返答・修正 |

### メモリ・コンテキスト管理

| コマンド | 概要 | 活用場面 |
|---------|------|---------|
| `/memory` | プロジェクト・個人レベルのメモリを確認・追加 | セッションをまたいだ情報の保持 |
| `/compact` | 会話履歴を要約してコンテキストを節約 | 長いセッションでの速度改善 |
| `/clear` | 会話履歴をリセット | 新しいタスクへの切り替え |

### 診断・ユーティリティ

| コマンド | 概要 | 活用場面 |
|---------|------|---------|
| `/doctor` | 環境・設定を診断 | インストール後のセットアップ確認 |
| `/cost` | セッションの使用コストを表示 | 費用の確認・管理 |
| `/status` | ツールの接続状態とモデル情報を表示 | MCP サーバーの疎通確認 |
| `/mcp` | MCP サーバーの一覧・管理 | 外部ツール連携の確認 |
| `/help` | **その環境で使えるコマンド一覧**を表示 | 使い方がわからないとき |

### エディタ・ターミナル連携

| コマンド | 概要 | 活用場面 |
|---------|------|---------|
| `/vim` | Vim キーバインドの有効化・無効化 | Vim ユーザーの操作性改善 |
| `/terminal-setup` | ターミナルへの Shift+Enter キーバインド設定 | 複数行入力の利便性向上 |
| `/release-notes` | 最新のリリースノートを表示 | アップデート内容の確認 |

## Web 版のスキルコマンド

[Claude Code on the Web](https://claude.ai/code)（ブラウザ版・モバイル版）では、複雑な処理をひとまとめに実行するスキルをスラッシュコマンドで呼び出せます。**ローカルの CLI とは利用できるものが異なります。**

### 開発ワークフロー

| コマンド | 概要 |
|---------|------|
| `/init` | `CLAUDE.md` をコードベースのドキュメントとして自動生成 |
| `/run` | プロジェクトのアプリを起動して実際の動作を確認 |
| `/verify` | コード変更が意図通りに動作するかアプリを実行して検証 |

### コードレビュー・品質

| コマンド | 概要 |
|---------|------|
| `/code-review` | 現在の差分を正確性・効率性の観点でレビュー |
| `/code-review high` | より広い範囲をカバーする詳細レビュー |
| `/code-review ultra` | クラウドで複数エージェントが並行実行するディープレビュー |
| `/code-review --comment` | レビュー結果を PR のインラインコメントとして投稿 |
| `/code-review --fix` | レビュー結果を自動で修正として適用 |
| `/simplify` | 差分を確認して簡潔化・クリーンアップを自動適用 |
| `/review` | プルリクエスト全体をレビュー |
| `/security-review` | セキュリティの観点で差分を詳細レビュー |

### 設定・パーミッション

| コマンド | 概要 |
|---------|------|
| `/update-config` | `settings.json` でハーネスの設定を更新 |
| `/fewer-permission-prompts` | 許可リストを追加して権限確認のプロンプトを減らす |
| `/keybindings-help` | キーボードショートカットのカスタマイズ支援 |
| `/session-start-hook` | セッション開始時のフック（SessionStart hook）を設定 |

### API 開発・自動化

| コマンド | 概要 |
|---------|------|
| `/claude-api` | Claude API / Anthropic SDK を使ったアプリの構築・デバッグ |
| `/loop 5m /code-review` | 指定間隔でコマンドを繰り返し実行（例: 5 分ごと） |

## キーボードショートカット

CLI・デスクトップでよく使うキーバインドです。**ショートカットはプラットフォームとターミナルによって変わります。**

| ショートカット | 動作 |
|--------------|------|
| `Ctrl+C` | 実行中の処理を中断。何も動いていなければ入力をクリアし、続けて押すと終了 |
| `Ctrl+D` | セッションを終了（確認のうえ、続けて押すと確定）。入力中は次の文字を削除 |
| `Ctrl+L` | 画面を再描画 |
| `↑` / `↓` | 入力履歴を遡る |
| `Ctrl+R` | 入力履歴を逆方向に検索 |
| `Tab` | スラッシュコマンドの補完 |
| `Shift+Enter` | 改行（`/terminal-setup` で設定後） |
| `Esc` | 入力をキャンセル |

> macOS で `Alt`（Option）系のショートカットを使うには、ターミナル側で Option キーを Meta として扱う設定が必要です。詳細と全ショートカットは [Interactive mode](https://code.claude.com/docs/en/interactive-mode) を参照してください。
