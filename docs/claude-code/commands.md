# Claude Code コマンド一覧（付録）

> **対象ツール**: Claude Code ｜ **実行環境**: CLI（ターミナル/デスクトップ） / Chat UI（Web） ｜ **対象読者**: エンジニア ｜ **最終更新**: 2026-10-10

> [!IMPORTANT]
> **このページはスナップショットです。** 組み込みコマンドとショートカットは更新が頻繁で、実際に使えるものは Claude Code のバージョン・実行環境・プラットフォームによって変わります。**正確な最新版は公式リファレンスを一次情報として確認してください。**
>
> - [Commands](https://code.claude.com/docs/en/commands) — 組み込みコマンドとバンドルスキルの完全なリファレンス

>
> セッション中に `/help` を実行すると、**その環境で実際に使えるコマンド**が一覧表示されます。迷ったらこれが最も確実です。

仕組みそのもの（CLAUDE.md・Skills・フック・MCP 等）の解説は [Claude Code のカスタマイズ機能](basics.md) を参照してください。

## 組み込みスラッシュコマンド

チャット入力欄で `/` に続けてコマンド名を入力します。以下は 2026-10-10 に[公式リファレンス](https://code.claude.com/docs/en/commands)で確認した抜粋です（全 100 種類以上あるため、日常的に使うものに絞っています）。

### プロジェクト初期化・設定

| コマンド | 概要 | 活用場面 |
|---------|------|---------|
| `/init` | `CLAUDE.md` を自動生成してプロジェクトの構成を記録 | 新規リポジトリへの導入時 |
| `/config` | 設定画面を開く。`key=value` を渡せば直接変更できる（テーマ・モデル・エディタモード等） | 初期セットアップ・Vim モードの切り替え |
| `/model` | 使用するモデルを切り替え、新規セッションの既定として保存 | タスクに応じた使い分け |
| `/effort` | 推論の努力度（`low`〜`xhigh` / `max` / `auto`）を設定。`status` で現在値を表示 | 難しいタスクで深く考えさせたいとき |
| `/permissions` | ツールの許可・確認・拒否ルールを管理 | 自動実行を許可するコマンドの制御 |
| `/statusline` | ステータスラインを設定（引数なしでシェルのプロンプトから自動構成） | 表示のカスタマイズ |
| `/import` | Codex・Gemini CLI・Cursor の指示ファイル・MCP サーバー・コマンド・サブエージェント・スキルを取り込む。`--dry-run` で書き込まずに確認（v2.1.213 以降。Cursor は v2.1.265 以降） | 他のエージェントからの移行 |

### 会話・コンテキストの管理

| コマンド | 概要 | 活用場面 |
|---------|------|---------|
| `/context` | コンテキスト使用量をグリッド表示し、圧迫している要因を示す | 動作が重い・長すぎると感じたとき |
| `/compact` | 会話履歴を要約してコンテキストを節約（要約の観点を引数で指定可） | 長いセッションでの速度改善 |
| `/autocompact` | 自動要約が走るしきい値（例: `500k`）を設定 | 自動要約のタイミングを調整したいとき |
| `/clear` | 新しい会話を開始（引数の名前は `/resume` の一覧に残る） | 別タスクへの切り替え |
| `/resume` | ID・名前を指定、または一覧から会話を再開 | 昨日の続きから作業する |
| `/rewind` | 会話とコードを前の時点へ巻き戻す（別名 `/checkpoint` / `/undo`） | 変更をやり直したいとき |
| `/branch` | 現時点から会話を分岐し、元の会話を残したまま別方針を試す | 方針を比較したいとき |
| `/fork` | 会話をコピーしてバックグラウンドセッションにし、手元は作業を続ける | 別観点の作業を並行させたいとき |
| `/memory` | `CLAUDE.md` の編集、自動メモリの有効・無効と内容確認 | セッションをまたいだ情報の保持 |

### 作業の進め方・並行作業

| コマンド | 概要 | 活用場面 |
|---------|------|---------|
| `/plan` | プランモードに入る。説明を渡すとその作業から始める（例: `/plan 認証のバグを直す`） | 大きな変更の前に方針を確認したいとき |
| `/goal` | 完了条件を設定し、満たすまでターンをまたいで作業を続けさせる。`clear` で解除 | 終わりの条件がはっきりした作業 |
| `/btw` | 会話の履歴に残さずに、今のセッションについて横から質問する | 作業を止めずに確認したいとき |
| `/subtask` | 会話全体を引き継いだサブエージェントをバックグラウンドで動かし、結果をこの会話へ戻す（v2.1.212 以降。それ以前は `/fork` がこの動作） | 手元の作業と並行させたい小さな作業 |
| `/background` | 今のセッションごとバックグラウンドのエージェントにして端末を空ける（別名 `/bg`）。`claude agents` で監視 | 長い作業を任せて端末を使いたいとき |

`/goal` と `/btw` の書き方、Codex・Copilot CLI との違いは [作業中のエージェントへの指示の出し分け](../dev-methods/agent-commands.md) を参照してください。

### レビュー・品質管理

| コマンド | 概要 | 活用場面 |
|---------|------|---------|
| `/code-review` | 差分・PR 番号・ブランチ・パスの正しさをレビュー。努力度（`low`〜`max`）を指定でき、`--fix` で修正適用、`--comment` で PR へインライン投稿、`ultra` でクラウドの多エージェントレビュー | 変更のセルフレビュー |
| `/review` | `/code-review` の別名（同じ努力度・フラグを取る） | PR 番号を指定したレビュー |
| `/simplify` | 変更部分の再利用・簡素化・効率・抽象度を 4 つのエージェントが並行レビューし、修正まで適用（バグは探さない。パスや PR を指定可） | 実装後のクリーンアップ |
| `/ultrareview` | `/code-review ultra` の別名。クラウドのサンドボックスで多エージェントの深いレビュー（Pro・Max は 3 回無料、以降は usage credits） | マージ前の重い変更 |
| `/security-review` | 現在のブランチの差分をセキュリティ観点で分析（`origin` が必要） | リリース前の確認 |

### 拡張機能の管理

| コマンド | 概要 | 活用場面 |
|---------|------|---------|
| `/plugin` | プラグインの一覧・インストール・有効化・無効化 | 配布された拡張の導入 |
| `/skills` | 利用可能なスキルの一覧（トークン数順の並べ替え・可視性の切り替え） | どのスキルが読み込まれるかの確認 |
| `/skill-doctor` | 各スキルのコンテキスト消費と使用頻度を表示し、無効にしてよいスキルを探す（v2.1.252 以降） | スキルの棚卸し |
| `/reload-skills` | ディスク上で追加・変更したスキルとコマンドを、再起動せずに読み込み直す | スキルを編集しながら試すとき |
| `/hooks` | ツールイベントに設定されたフックを確認 | 自動実行の設定確認 |
| `/mcp` | MCP サーバーの接続・OAuth 認証の管理（`reconnect` / `enable` / `disable`） | 外部ツール連携の確認 |

### 診断・ユーティリティ

| コマンド | 概要 | 活用場面 |
|---------|------|---------|
| `/status` | 設定画面の Status タブ（バージョン・モデル・アカウント・接続状態） | 環境の確認 |
| `/usage` | セッションのコスト、プランの使用状況、利用状況の統計（`/cost`・`/stats` は別名） | 費用と上限の確認 |
| `/doctor` | セットアップを診断し、確認のうえ修正する（別名 `/checkup`）。`prompt-audit` で指示ファイルを点検（v2.1.283 以降） | インストール後のトラブル・モデル更新後の点検 |
| `/diff` | 未コミットの変更とターンごとの差分を対話的に閲覧 | 何が変わったかの確認 |
| `/tasks` | セッション内のバックグラウンド作業と、終了したものを含むサブエージェントの状況（別名 `/bashes`） | 並行作業の把握 |
| `/release-notes` | バージョンを選んでリリースノートを表示 | アップデート内容の確認 |
| `/terminal-setup` | Shift+Enter 等のキーバインドを設定（必要なターミナルでのみ表示） | 複数行入力の利便性向上 |
| `/help` | **その環境で使えるコマンド一覧**を表示 | 使い方がわからないとき |

このページの改訂で確認できた、**なくなった／意味が変わったコマンド**です。古い記事やメモをそのまま実行すると失敗するので注意してください。

| コマンド | 現在の扱い |
|---------|-----------|
| `/settings` | 存在しない。設定は `/config`、状態確認は `/status` |
| `/vim` | v2.1.92 で削除。`/config` → Editor mode で切り替える |
| `/pr-comments` | v2.1.91 で削除。PR のコメントは Claude に直接依頼する |
| `/cost` | `/usage` の別名。内訳表示は `/usage` に集約 |
| `/ultraplan` | 削除。プランモード（`/plan` または `Shift+Tab`）を使う |
| `/fork` | v2.1.212 以降は「会話をコピーした**別の**バックグラウンドセッション」を作る。会話を引き継ぐサブエージェントは `/subtask` |
| `/agents` | v2.1.198 以降は案内を表示するだけ。サブエージェントは Claude に作らせるか `.claude/agents/` を直接編集する |

## バンドルされたスキル

`/code-review` や `/doctor` のように、**スキルとして実装された組み込みコマンド**があります（公式リファレンスで `[Skill]` と表記されているもの）。通常のコマンドと同じく `/` から呼び出せますが、実体はスキルなので、呼び出したときだけ内容が読み込まれます。

| コマンド | 概要 |
|---------|------|
| `/code-review` / `/simplify` | 差分のレビューとクリーンアップ |
| `/batch` | コードベース全体の大きな変更を 5〜30 の独立した単位に分け、承認後にそれぞれ別の worktree で並行実行 |
| `/doctor` | セットアップ診断と修正、`prompt-audit` による指示ファイルの点検 |
| `/run` / `/verify` | プロジェクトのアプリを実際に起動して、変更が動くことを確認 |
| `/debug` | デバッグログを有効化し、セッションのログを読んで原因を切り分け |
| `/loop` | プロンプトを一定間隔（または自動ペース）で繰り返し実行 |
| `/claude-api` | Claude API / Anthropic SDK 向けのリファレンスを読み込む |
| `/dataviz` | グラフ・ダッシュボード設計のガイド |
| `/fewer-permission-prompts` | 権限確認を減らす許可リストを生成 |

このほか、`/deep-research` は**バンドルされた workflow**（多数のサブエージェントでウェブ検索と照合を行い、出典付きのレポートを作る）として提供されています。

> **実行環境で増減します。** [Claude Code on the Web](https://claude.ai/code) やデスクトップでは、`/update-config`・`/keybindings-help`・`/session-start-hook` のような環境固有のスキルが加わることがあります。プラグインをインストールすれば、そのスキルも `/` から呼べます。**その場で使える一覧は `/help` または `/skills`** で確認してください。

## キーボードショートカット

CLI・デスクトップでよく使うキーバインドです。**ショートカットはプラットフォームとターミナルによって変わります。**

| ショートカット | 動作 |
|--------------|------|
| `Ctrl+C` | 実行中の処理を中断。何も動いていなければ 1 回目で入力をクリアし、2 回目で終了 |
| `Ctrl+D` | セッションを終了（確認のうえ、続けて押すと確定）。入力中は次の文字を削除 |
| `Ctrl+L` | 画面を再描画 |
| `↑` / `↓` | 入力履歴を遡る |
| `Ctrl+R` | 入力履歴を逆方向に検索 |
| `Tab` | 補完の候補を確定 |
| `Shift+Enter` | 改行（`/terminal-setup` で設定後） |
| `Shift+Tab` | 権限モードを切り替える（Manual → `acceptEdits` → `plan` など） |
| `Esc` | 応答やツール実行を途中で止める（そこまでの作業は残る）。ダイアログを閉じる |
| `Esc` を 2 回 | 入力中なら下書きを消す（履歴に保存）。入力が空なら巻き戻しのメニューを開く |
| `Ctrl+B` | 実行中の Bash コマンドやエージェントをバックグラウンドへ回す（tmux では 2 回） |
| `Ctrl+O` | ツールの実行内容を詳しく見る transcript 表示を切り替える |

> macOS で `Alt`（Option）系のショートカットを使うには、ターミナル側で Option キーを Meta として扱う設定が必要です。詳細と全ショートカットは [Interactive mode](https://code.claude.com/docs/en/interactive-mode) を参照してください。
