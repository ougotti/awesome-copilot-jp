# 事務・バックオフィス活用ガイド

> **対象ツール**: Claude.ai・Claude Code ｜ **対象読者**: 非エンジニア（事務・経理・総務） ｜ **最終更新**: 2026-07-29

> コードを書かない**事務・経理・総務・営業事務**の現場で、生成AIを日々の業務効率化に使うための実践ガイドです。Word／Excel／PowerPoint／PDF を扱う [anthropics/skills](https://github.com/anthropics/skills) のドキュメント処理スキルを中心に、「何ができるか」ではなく「**どの業務がどう楽になるか**」の視点でまとめています。

## このガイドの読み方

- エンジニア向けの設定知識は不要です。**Claude.ai の有料プラン**ではドキュメント処理スキル（docx / pdf / pptx / xlsx）が標準で使えます。
- 各スキルの技術的な詳細は [Anthropic 公式スキル解説](../claude-code/official-skills.md) を参照してください。
- 金融・経理に特化した業務（決算照合・月次決算・KYC 等）は [金融サービス向けスキル](financial-services.md) を参照してください。

---

## まず使えるドキュメント処理スキル

| スキル | 扱うファイル | 事務での主な用途 |
|-------|------------|----------------|
| **docx** | Word（.docx） | 議事録、案内文、契約書ドラフト、報告書の作成・編集 |
| **xlsx** | Excel（.xlsx） | 集計表、名簿、勤怠・経費の整理、数式入りシート作成 |
| **pptx** | PowerPoint（.pptx） | 提案資料、社内報告スライド、研修資料の作成 |
| **pdf** | PDF | フォーム入力、PDF からのテキスト・表抽出、結合・分割 |

> これらは Claude.ai 有料プランに標準搭載。Claude Code では `/plugin install document-skills@anthropic-agent-skills` で導入できます。

## 業務シナリオ別レシピ

### 📝 議事録・文書作成

- **会議メモ → 整った議事録**：箇条書きの走り書きを貼り付け、「決定事項・ToDo・担当者・期日」に整理した Word を生成
- **定型案内文の量産**：テンプレートと宛先リストを渡し、宛名差し込み済みの案内文を一括作成
- **長文資料の要約**：PDF や Word の長い資料を、要点 5 つ＋アクション項目に圧縮

### 📊 表計算・集計

- **バラバラの表を統合**：複数シート・複数ファイルの表を、共通フォーマットに正規化して 1 つの集計表へ
- **数式・ピボット入りシート生成**：「月別・部門別の経費集計」など、関数や条件付き書式まで入った Excel を作成
- **データのクレンジング**：表記ゆれ（全角／半角、会社名の末尾「株式会社」有無など）を統一
- **シートの監査**：既存 Excel の計算ミス・循環参照・壊れた参照を検出（financial-analysis の Excel 監査スキルが有用）

### 📑 請求書・帳票

- **請求書・見積書のドラフト**：取引内容を渡し、定型フォーマットの帳票を作成（金額・税計算の確認は必須）
- **帳票 PDF からの情報抽出**：受領した請求書 PDF から日付・金額・取引先を表に転記
- **フォーム PDF への入力**：申請書テンプレート PDF に必要事項を流し込み

### 🎤 プレゼン・報告資料

- **報告内容 → スライド化**：文章の報告メモから、見出し・図解・箇条書き構成のスライドを生成
- **ブランドテンプレート適用**：自社の PowerPoint テンプレートに沿った体裁で出力
- **データ → グラフ付き資料**：集計結果からグラフ入りの報告スライドを作成

### 📨 メール・社内コミュニケーション

- **問い合わせ対応の下書き**：要件を渡して丁寧なビジネスメールを作成（[internal-comms スキル](../claude-code/official-skills.md)）
- **多言語対応**：英語メールの下書き・和訳・トーン調整

## 経理・財務寄りの業務

経理・財務など、より専門的な事務には金融サービス向けスキルの考え方が応用できます。

| 業務 | 参考スキル | 概要 |
|-----|-----------|------|
| 月次決算の見越計上・差異説明 | Month-End Closer | 仕訳ドラフトと差異コメントの自動生成 |
| 勘定照合（突合） | GL Reconciler | 台帳と明細のブレーク検出・原因候補の提示 |
| 取引先審査 | KYC Screener | 書類のパース → 社内ルールでの確認 |

→ 詳細は **[金融サービス向けスキル](financial-services.md)** を参照。

## 安全に使うためのポイント

> [!IMPORTANT]
> 生成AIの出力は**必ず人が確認**してください。特に以下に注意します。

- **金額・税・日付などの数値**は鵜呑みにせず検算する
- **個人情報・機密情報**を入力してよいか、社内ルールを確認する（利用するプラン・契約の取り扱い範囲を確認）
- **契約書・法的文書**は有資格者（法務・税理士等）のレビューを受ける
- 自動生成された数式やマクロは、提出前に動作と結果を確認する

## 始め方（非エンジニア向け）

1. **Claude.ai の有料プラン**に登録すると、ドキュメント処理スキルがすぐ使えます。
2. チャットに**ファイルを添付**し、やりたいことを日本語で指示するだけ（例：「この議事録メモを、決定事項とToDoに分けた Word にして」）。
3. 出力ファイルをダウンロードして確認・微修正。

より高度に自動化したい場合は [Claude Code](../claude-code/basics.md) や [Microsoft 365 連携](financial-services.md)（financial-services リポジトリに同梱）も検討できます。
