# 生成AIを業務で安全に使う

> **対象ツール**: ツール非依存 ｜ **実行環境**: Chat UI / IDE / CLI（共通） ｜ **対象読者**: 全職種 ｜ **最終更新**: 2026-08-01

業務で生成AIを使うときの共通ルールをまとめたページです。**個別のユースケースページでは繰り返さず、ここを参照します。**

---

## 3 つの原則

| 原則 | 意味 |
|-----|------|
| **出力はドラフト** | 生成物は完成品ではなく下書きです。そのまま提出・送信・登録しない |
| **入れてよい情報を先に決める** | 入力してよい情報の範囲を、社内ルールと契約で先に確認する |
| **確認する人を決める** | 誰が何を確認して承認するかを、作業を始める前に決めておく |

---

## 入力する前に確認すること

### 情報の取り扱い

- **個人情報**（氏名・連絡先・マイナンバー・人事評価など）を入力してよいか、社内ルールを確認する
- **機密情報**（未公表の決算数値、取引条件、ソースコード、顧客情報）の入力可否を、利用中のプラン・契約の取り扱い範囲と照らして確認する
- 判断がつかない場合は、**固有名詞や金額を伏せ字にして構造だけを相談する**のが安全です

### 外部への送信とファイルの保持

- 生成AIサービスへの入力は、**社外のサーバーへ情報を送信する行為**です。社内の情報持ち出しルールの対象になり得ます
- 添付したファイルや会話履歴がどれくらい保持されるか、**学習に使われるか**は、プラン・契約・設定によって異なります。組織で使う場合は管理者に確認してください
- 外部サービスへ接続する機能（コネクタ、MCP、プラグイン）は、**接続先と権限範囲**を導入前に確認してください

---

## 出力を受け取った後に確認すること

用途を問わず、次の観点は必ず人が確認します。

| 観点 | 具体的に見るところ |
|------|-----------------|
| **数値** | 金額・税額・比率・日付。合計が合うか、税率が正しいか、期間がずれていないか |
| **固有名詞** | 会社名・人名・製品名・部署名。実在するか、表記が正しいか |
| **事実** | 引用・出典・統計値。もっともらしい誤り（ハルシネーション）がないか |
| **抜け漏れ** | 元資料にあった項目が落ちていないか。要約で重要な条件が消えていないか |
| **体裁** | 提出先の様式・フォーマットに合っているか |
| **自動生成物の動作** | 数式・マクロ・スクリプトは、提出・実行前に結果を確かめる |

---

## 有資格者の確認が必要なもの

以下は生成AIの出力をそのまま使わず、**必ず有資格者のレビュー**を受けてください。

| 分野 | 確認する人 |
|-----|----------|
| 契約書・利用規約・法的文書 | 法務・弁護士 |
| 税務処理・申告に関わる判断 | 税理士・経理責任者 |
| 決算・開示に関わる数値 | 会計士・経理責任者 |
| 投資判断・金融商品の説明 | 有資格の担当者（生成AIの出力は投資助言ではありません） |
| 人事評価・労務判断 | 人事責任者 |
| 医療・安全に関わる判断 | 各分野の専門家 |
